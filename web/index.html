About this page

Every number on this page was computed by our Python code (src/twoparty). When you change numbers yourself, the page recomputes them in your browser with the same steps, which are checked against Python test cases.

HSG Bachelor project on two-party ECDSA, supervised by Prof. Katerina Mitrokotsa and Nan Cheng. Source code. Educational code: not constant-time and not safe against side channels. The demo keys are public. Never use this code or these numbers for real funds.
